# Quiz2notes

## Идея проекта

**Quiz2notes** — Telegram-бот для генерации учебных карточек и квизов из пользовательских конспектов.

Пользователь отправляет боту конспект в формате `.txt` или `.md`, после чего система извлекает ключевые термины и определения, создает карточки и запускает квиз для повторения материала.

## Реализованные возможности

### Загрузка конспектов
- Поддержка `.txt` и `.md`
- Проверка расширения файла
- Проверка пустых файлов
- Автоматическое создание папки `uploads`
- Сохранение пользовательских файлов

### Извлечение определений
- Regex extraction
- AI extraction для неструктурированных конспектов
- Поддержка различных формулировок определений
- Удаление дубликатов
- Объединение regex и AI extraction

### Quiz-система
- Multiple choice карточки
- Команда `/quiz`
- Команда `/stop`

### Статистика
- Команда `/stats`:
  - Подсчет правильных и неправильных ответов
  - Сохранение терминов с ошибками


### Режим повторения
- Команда `/repeat`:
  - повторение карточек, в которых пользователь ошибался
  - Автоматическое удаление карточки из repeat после правильного ответа

### Просмотр определений
- Команда `/definitions` - вывод всех найденных определений для удобного повторения

### Хранение данных
- Используется TinyDB
- Статистика и ошибки сохраняются между перезапусками бота

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Показать приветственное сообщение |
| `/quiz` | Запустить квиз по загруженному конспекту |
| `/stop` | Досрочно остановить текущий квиз |
| `/stats` | Показать статистику пользователя |
| `/repeat` | Повторить карточки с ошибками |

## Профилирование

Для анализа производительности проекта использовались:
- `timeit`
- `time.perf_counter`
- `statistics`

Были протестированы:
- regex extraction
- AI extraction
- генерация quiz-карточек
- TinyDB storage
- полный pipeline обработки конспекта

Тестирование проводилось на увеличенном наборе данных
(текст был искусственно увеличен в 50 раз).

### Результаты

| Component | Average Time | Per Call |
|---|---|---|
| Regex Extraction | 1.055 sec | 0.01055 sec |
| AI Extraction | 0.00085 sec | 0.000008 sec |
| Quiz Generation | 1.017 sec | 0.01017 sec |
| Storage Operations | 0.159 sec | 0.00159 sec |
| Full Pipeline | 1.385 sec | 0.01385 sec |

### Вывод

Даже при обработке увеличенного тестового текста
полный pipeline выполняется
за несколько секунд.

Полное время обработки зависит
от размера загружаемого текста,
количества найденных определений
и числа regex-проверок.

При увеличении объема конспекта
время extraction и генерации карточек
увеличивается линейно,
так как обработка выполняется последовательно
для каждой строки текста.

## Как запустить проект

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

---

### 2. Создать `.env`

```text
BOT_TOKEN=your_telegram_bot_token
```

---

### 3. Запустить бота

```bash
python -3.11 main.py
```

### 4. Запуск profiling

```bash
python real_profile.py
```

## 5. Тестирование

```bash
python -m pytest
```
